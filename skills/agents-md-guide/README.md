# agents-md-guide

프로젝트 루트의 `AGENTS.md`를 만들고, 검토하고, 개선하기 위한 Codex용 스킬입니다. 다음 세션의 에이전트도 알아야 할 프로젝트 고유 규칙을 작업 중 발견하면 능동적으로 제안합니다.

기본 탐색 범위는 저장소 루트입니다. 루트의 `AGENTS.md`, README, 루트에서 직접 연결된 문서와 설정을 확인하며, 하위 디렉터리를 재귀적으로 탐색하거나 하위 `AGENTS.md`를 임의로 만들지 않습니다.

검토나 일반 작업 중에는 파일을 변경하지 않습니다. 지속적으로 남길 만한 정보가 발견되면 최종 보고에 `지속 지식 후보`로 아래 두 항목만 제시합니다.

- 후보 규칙
- 근거

사용자가 `AGENTS.md` 또는 상세 문서의 생성·수정·추가를 명시적으로 요청한 경우에만 파일을 변경합니다. 이미 문서화된 규칙은 중복 제안하지 않으며, 긴 설명이나 작업 절차는 기존 문서 구조에 맞춰 분리하고 `AGENTS.md`에서는 링크로 안내합니다.

프로젝트 지침과 다른 작업을 사용자가 명시적으로 요청하면 해당 요청 범위에서만 예외로 취급합니다. 이 예외를 지속 규칙으로 기록하거나 기존 지침을 대체한다고 가정하지 않습니다.
