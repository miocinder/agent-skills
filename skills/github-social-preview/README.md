## GitHub 소셜 프리뷰 규격

GitHub에서 레포지토리를 소셜 미디어에 공유할 때 표시되는 미리보기 이미지를 설정할 수 있습니다. 이미지는 최소 **640×320px** 이상이어야 하며, 가장 보기 좋은 권장 크기는 **1280×640px**입니다. 이 스킬은 권장 크기에 맞춰 이미지를 생성합니다.

## 생성 방식

Codex의 GPT 이미지 생성이 프롬프트에 따라 텍스트 없는 베이스 이미지를 새로 만듭니다. 스킬은 좌측에 텍스트를 위한 여백을 남기고 우측에 추상 그래픽을 배치하도록 구도·색상·안전 여백을 지시합니다.

이미지 모델에는 최종 글자를 맡기지 않습니다. Sharp가 별도로 제목·설명·태그를 정확하게 합성하므로, 한글 오타나 글자 깨짐 없이 일관된 결과를 만들 수 있습니다. 마지막으로 PNG의 크기와 안전 여백을 검증하고 EXIF, ICC, IPTC, XMP 메타데이터를 제거합니다.

밝고 따뜻한 배경에는 `warm` 테마를 사용해 짙은 플럼 계열 텍스트를 적용하고, 어둡거나 차가운 배경에는 `dark` 테마의 밝은 텍스트를 사용합니다.

한글 텍스트에는 사용 범위와 라이선스가 명확한 글꼴을 로컬 경로로 지정해 사용합니다. 글꼴 파일은 스킬에 포함하지 않습니다.
