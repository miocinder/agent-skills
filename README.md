# 개인용 Agent Skills

이 저장소는 다양한 반복 업무에 사용하기 위해 관리하는 개인용 에이전트 스킬 모음입니다. **한국어를 기본 언어로 관리**하고, **Codex를 주 실행 환경으로 사용**합니다. 필요에 따라 공개하지만 특정 팀이나 범용 제품을 위한 공식 스킬 컬렉션은 아닙니다.

## 스킬의 범위와 적용 방식

이 저장소의 스킬은 특정 제품, 서비스, 팀, 코드베이스에 종속되지 않는 개인용 공통 작업 규칙입니다. Git 작업, 이미지 처리, 정적 목업 제작, UI 품질 검토처럼 여러 프로젝트에서 반복되는 작업의 기본 절차와 안전 기준을 제공합니다.

따라서 이 스킬들은 프로젝트 고유의 디자인 시스템, 기술 스택, 도메인 규칙, 배포 정책을 대체하거나 강제하지 않습니다. 실제 작업에서는 해당 프로젝트의 `AGENTS.md`, `DESIGN.md`, README, 개발 문서 및 사용자의 명시적 요구사항을 우선합니다.

프로젝트별로 재사용할 규격이 있다면, 이 저장소의 공통 스킬을 기반으로 필요한 지침을 해당 프로젝트에 추가하는 방식을 권장합니다.

## 면책 안내

이 저장소의 스킬과 예시는 별도의 품질 보증 없이 제공됩니다. 사용자는 자신의 환경과 목적에 맞는지 직접 검토하고, 실행·수정·배포에 따른 위험과 책임을 부담합니다. 이 저장소의 작성자는 스킬 사용 또는 사용 불가로 발생할 수 있는 직간접적 손해에 대해 책임을 지지 않습니다.

## 이용 및 재배포 안내

이 저장소의 스킬은 개인 작업 또는 조직 내부 업무를 위해 설치·실행·수정할 수 있으며, 스킬을 이용해 만든 결과물은 개인적 또는 상업적으로 이용할 수 있습니다.

저작권자의 사전 서면 허락 없이 스킬의 원본 또는 수정본을 스킬 마켓, 웹사이트, 저장소, 패키지, 번들 등에 무료 또는 유료로 재배포·재판매·게시·미러링하거나 제3자에게 라이선스 또는 접근권을 제공해서는 안 됩니다.

GitHub 서비스 내 열람과 fork는 GitHub 약관이 허용하는 범위에 한하며, 외부 서비스나 마켓에 배포할 권리를 의미하지 않습니다. 이 조건을 위반하면 위에서 허용한 이용 권리는 종료됩니다.

## 설치

```bash
# 포함된 스킬 목록 보기
npx skills add miocinder/agent-skills --list

# Codex에 전역 설치
npx skills add miocinder/agent-skills --agent codex --global

# 현재 프로젝트에만 설치
npx skills add miocinder/agent-skills --agent codex
```

## 업데이트

`npx skills`로 설치한 스킬은 원본 저장소와 스킬 경로를 추적할 수 있을 때 업데이트할 수 있습니다.

```bash
npx skills update <skill-name>  # 특정 스킬만 업데이트
npx skills update               # 설치된 스킬 전체 업데이트
npx skills update -g            # 전역 설치 스킬만 업데이트
npx skills update -p            # 프로젝트 설치 스킬만 업데이트
```
